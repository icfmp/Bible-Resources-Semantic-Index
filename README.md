# Bible Resources Semantic Index (BSI)

Independent open-source workspace for biblical entity and lexical indexes, including the BSI entity index and UBS Greek and Hebrew crosswalks.

This repository is being migrated from [`icfmp/Bible-Resources/bible-semantic-index`](https://github.com/icfmp/Bible-Resources/tree/main/bible-semantic-index). The original published releases remain available in Bible-Resources while workflows and delivery ownership are migrated.

**Source fidelity and redistribution:** Source revisions, editorial evidence, licenses and original data must remain traceable. Public source-pinned index data does not imply permission to publish every intermediate third-party dataset. Complete internal UBS/MACULA witness files require an independent rights review before publication.

**Migration status:** bootstrap only. Do not treat this repository as the canonical publisher until the independent source-pinned builds, CI, and release pipeline have passed.
