# BRSI V1 encyclopedia crosswalks

Reserved for independently reviewed BRSI entity → encyclopedia article
**identifier mappings**, one file per pinned encyclopedia edition.
Different homonymous people and places must remain distinct. Never copy
encyclopedia prose into BRSI, or equate similar article titles with verified
identities. Record explicit ambiguous/withheld cases rather than guessing.
See the [crosswalk policy](../README.md) and [schema](../schema.v1.json).
